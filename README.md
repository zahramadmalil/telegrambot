## 📖 درباره پروژه

این مخزن، یک **مجموعه آموزشی کامل و عملی** برای ساخت یک **ربات تلگرام (Telegram Bot)** با استفاده از کتابخانه `pyTelegramBotAPI` (Telebot) در زبان پایتون است.

در این پروژه، ما یک ربات جستجوی فیلم می‌سازیم که به یک API خارجی (moviesapi.ir) متصل می‌شود. کاربر می‌تواند نام یک فیلم را جستجو کند، لیست فیلم‌های محبوب را ببیند و با کلیک روی هر فیلم، اطلاعات کامل آن (کارگردان، بازیگران، امتیاز IMDB و...) را دریافت کند. همچنین نحوه ساخت منوهای شیشه‌ای (Inline) و کیبوردهای معمولی (Reply) آموزش داده می‌شود.

### 🗂️ فایل‌های پروژه

این پروژه شامل چندین فایل است که به مرور تکمیل شده‌اند:

| # | نام فایل | موضوع | سطح |
|---|---|---|---|
| ۱ | `base.py` | ذخیره توکن ربات (فایل تنظیمات) | 🟢 مقدماتی |
| ۲ | `app_api.py` | توابع ارتباط با API فیلم‌ها (نسخه ساده) | 🟡 متوسط |
| ۳ | `app.py` | ربات ساده با منو و دستورات پایه | 🟡 متوسط |
| ۴ | `app.callbak.py` | ربات ارسال مدیا (عکس و فایل) با دکمه‌های Inline | 🟡 متوسط |
| ۵ | `app_api.py` (نسخه پیشرفته) | توابع کامل API (جستجو، فیلم‌های محبوب، صفحه‌بندی) | 🔴 پیشرفته |
| ۶ | `bot.py` | ربات نهایی و کامل (جستجو + لاگ + صفحه‌بندی) | 🔴 پیشرفته |

> ⚠️ **توجه:** فایل `app_api.py` در طول تمرین تکمیل شده است. نسخه نهایی `bot.py` از نسخه پیشرفته `app_api.py` استفاده می‌کند.

## ✨ ویژگی‌های کلیدی

- ✅ **اتصال به API:** دریافت اطلاعات فیلم‌ها از `moviesapi.ir`.
- ✅ **دستورات متنی:** مدیریت دستورات `/start`, `/help`, `/about`.
- ✅ **منوی شیشه‌ای (Inline Keyboard):** دکمه‌های تعاملی برای نمایش اطلاعات فیلم.
- ✅ **کیبورد معمولی (Reply Keyboard):** منوی اصلی با دکمه‌های شیشه‌ای پایین صفحه.
- ✅ **ارسال مدیا:** ارسال عکس و فایل (PDF) از سیستم لوکال یا لینک آنلاین.
- ✅ **جستجوی هوشمند:** جستجوی فیلم بر اساس نام و نمایش نتایج.
- ✅ **صفحه‌بندی:** نمایش لیست فیلم‌های محبوب در صفحات مختلف.
- ✅ **لاگ‌گیری (Logging):** ذخیره تاریخچه جستجوهای کاربران در یک فایل متنی.

## 📘 مستندات فایل‌ها

### 📄 فایل `base.py` — تنظیمات
این فایل فقط شامل توکن ربات است. توکن را از @BotFather در تلگرام دریافت کنید.

### 📄 فایل `app_api.py` — ارتباط با API فیلم‌ها
این فایل شامل توابعی برای دریافت اطلاعات از سایت `moviesapi.ir` است.
- `get_movie_info_by_id(id)`: دریافت اطلاعات کامل یک فیلم با شناسه.
- `get_movie_info_by_name(name)`: جستجوی فیلم با نام.
- `get_popular_movies(page)`: دریافت لیست فیلم‌های محبوب با صفحه‌بندی.

### 📄 فایل `app.py` — ربات ساده
این فایل اولین نسخه ربات است و شامل موارد زیر است:
- دستور `/start` برای خوش‌آمدگویی.
- دستور `/help` برای راهنمایی.
- دستور `/news` برای نمایش دکمه‌های لینک به سایت‌های خبری.
- دستور `/menu` برای نمایش کیبورد معمولی.
- دستور `/movie` برای دریافت آیدی فیلم و نمایش اطلاعات آن.

### 📄 فایل `app.callbak.py` — ارسال مدیا
این فایل نحوه استفاده از دکمه‌های Inline را برای ارسال انواع مدیا آموزش می‌دهد:
- ارسال عکس از فایل لوکال.
- ارسال فایل PDF از فایل لوکال.
- ارسال عکس از لینک آنلاین.

### 📄 فایل `bot.py` — ربات نهایی (پیشرفته)
این فایل نسخه کامل و نهایی ربات است و شامل تمام قابلیت‌هاست:
- منوی اصلی با دکمه‌های «جستجوی فیلم»، «فیلم‌های محبوب» و «راهنما».
- جستجوی فیلم با نام و نمایش ۱۰ نتیجه اول به صورت دکمه.
- نمایش اطلاعات کامل فیلم با کلیک روی دکمه.
- صفحه‌بندی لیست فیلم‌های محبوب (صفحه قبل/بعد).
- ذخیره تاریخچه جستجوها در فایل `search_log.txt`.

## 🧠 مفاهیم کلیدی آموزش‌داده‌شده

<details>
<summary><b>🔹 ۱. Telebot چیست؟</b></summary>
Telebot یک کتابخانه پایتون برای ساخت ربات‌های تلگرام است. این کتابخانه ارتباط با سرورهای تلگرام را بسیار ساده می‌کند.
</details>

<details>
<summary><b>🔹 ۲. تفاوت Inline Keyboard و Reply Keyboard</b></summary>
- Inline Keyboard: دکمه‌هایی که زیر یک پیام خاص ظاهر می‌شوند و به آن پیام متصل هستند.
- Reply Keyboard: دکمه‌هایی که در پایین صفحه چت جایگزین کیبورد معمولی می‌شوند.
</details>

<details>
<summary><b>🔹 ۳. استفاده از register_next_step_handler</b></summary>
وقتی کاربر یک دکمه را می‌زند و ربات منتظر می‌ماند تا پاسخ متنی بعدی او را دریافت کند، از این تابع استفاده می‌کنیم. این کار باعث می‌شود ربات بتواند چند مرحله‌ای کار کند.
</details>

<details>
<summary><b>🔹 ۴. صفحه‌بندی با Callback Data</b></summary>
در دکمه‌های Inline، می‌توانیم یک متن پنهان (callback_data) قرار دهیم. وقتی کاربر کلیک می‌کند، این متن به ربات ارسال می‌شود. ما با بررسی این متن (مثلاً `more_movies_2`) می‌فهمیم کاربر می‌خواهد صفحه دوم را ببیند.
</details>

## 🐛 عیب‌یابی رایج (Troubleshooting)

| مشکل | راه‌حل |
|------|--------|
| `Unauthorized` | توکن ربات را در `base.py` بررسی کنید. |
| ربات پاسخ نمی‌دهد | مطمئن شوید اینترنت وصل است و فایل `bot.py` در حال اجراست. |
| خطای ارسال مدیا | مطمئن شوید پوشه `media` و فایل‌های داخل آن وجود دارند. |
| جستجو نتیجه نمی‌دهد | ممکن است API موقتاً قطع باشد. با نام دیگری امتحان کنید. |
